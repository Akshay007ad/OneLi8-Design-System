# @oneli8/react

OneLi8 Design System — Public Beta · Apache-2.0

## Install

```sh
npm install @oneli8/react@beta
```

The matching @oneli8/tokens dependency is installed automatically. This package
expects React 18+ in your application; React 18.3.1 is the tested version.

```jsx
import {Button, Icon} from '@oneli8/react';
import '@oneli8/react/styles.css';

<Button leadingIcon={<Icon name="add" />}>Add item</Button>
```

Public exports: Button, IconButton, Link, Icon and iconNames. Gem is available on
Button and IconButton. Full-system visual and assistive-technology certification
are not claimed.
