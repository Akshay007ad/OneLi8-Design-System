Gem angular bezel

Figma puts a 1px INSIDE GRADIENT_ANGULAR stroke on the Control frame with five stops symmetric about 0.54 — Inner Thin Cut on Filled (214:132), Cut Edge on Outline (210:112). CSS has no gradient border that follows border-radius, so this is a conic gradient masked to a hairline band on .ol8-field__control-stack::before. The plate is mid-tone because a 1px near-white ring is invisible against the page.
